# Completed Plans

Plans in this directory are finished. They're kept for design history and implementation detail.

- Current project status and remaining work: [`../STATUS.md`](../STATUS.md)
- Active plans: [`../todo/`](../todo/)

When a plan in `todo/` is fully implemented, move it here (`git mv todo/x.md done/x.md`),
update any links to it, and update its row in `STATUS.md` in the same commit.

Content lifecycle docs: start with `content_lifecycle_complete.md`.
