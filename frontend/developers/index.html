Developer Console

Build publishing flows that feel native to your app.

Register redirect URIs, issue OAuth consent requests, and let users publish immutable 256t content without hand-copying API keys.

Included in this first release Application registration, OAuth + PKCE, refresh rotation, per-app authorizations, and browser CORS for registered origins.

Quick start

Load the hosted SDK, configure your client, and redirect users into the OAuth consent screen.

<script type="module">
  import "https://hashbin.org/sdk/hashbin.js";

  hashbin.configure({
    clientId: "app_123",
    redirectUri: "https://your-app.example/hashbin/callback",
    contentBaseUrl: "https://256t.us"
  });

  await hashbin.authorize({
    scopes: ["content:write", "balance:read"],
    mode: "redirect"
  });
</script>

GitHub Pages Upload Utilities

You can use one of two hosted upload tools on GitHub Pages:

  • Upload via API key: Fast/manual flow using a HashBin API key. Supports choosing retention per upload.
  • Upload via registered app: OAuth flow with app-scoped, revocable access. No API key sharing in the page. Uses account default retention for OAuth publishing.
