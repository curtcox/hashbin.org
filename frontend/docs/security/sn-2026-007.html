SN-2026-007: Redirect saves are limited to 512 KiB

Redirect mode carries the document in the URL fragment, so the SDK limits it to 512 KiB. Apps that must use redirect mode, such as cross-origin isolated apps, cannot publish larger documents directly.

Found2026-10-28, migrating apptron, whose disk overlays can reach 5 MiB
AffectedRedirect-only apps
SeverityLow: a usability limit
StatusOpen

What was wrong

Fragment length is the only channel a redirect offers without a server-side handoff.

How it was detected

Comparing apptron's overlay size limit with the SDK's redirect limit.

How it can be demonstrated

Call publish() in redirect mode with more than 512 KiB: the SDK refuses.

How it can be fixed

  • App-side: apptron asks the user to download the file and upload it on hashbin.org.
  • HashBin-side (planned): a larger handoff, such as a file chooser on the Publish page.
